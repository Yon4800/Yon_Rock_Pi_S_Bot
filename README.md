# Yon_Rock_Pi_S_Bot (Radxa Rock Pi S)

Radxa Rock Pi S（ロックス）の Mastodon / Hollo 対応AIボットです。

## 主な機能
- **`+LLM`**: キャラクター会話（スレッド履歴・添付画像対応）
- **`+S` / `+SONG` / `+MUSIC` / `作曲` / `曲作って`**: AIが曲名・BPM・音階・楽器構成を決め、多楽器ミックスの狂気ソング（MP3 + MIDI）を生成
- **`+SV`**: ロックス自作の狂った歌詞をフォルマント歌唱シンセで歌うボーカル入りソング（MP3 + MIDI）を生成
- **06:00 目覚ましソング**: 毎朝 06:00 に目覚ましソング（MP3 + MIDI）を自動投稿
- **キチガイゲージ**: 会話で上昇・時間経過で回復し、100%でオーバーヒート爆発
- **ログインボーナス（`+LOGBO` / `+BONUS` / 通常会話）**: 1日1回ポイント付与、10ポイントで激レアSBCアイテムを授与
- **`+INFO`**: ゲージ・ログインボーナス・獲得アイテム・嘘スペックを確認
- **`+TALK`**: 他SBCボットとのグループ会話リレー（2周・全8回）
- **定期投稿**: 毎日 12:00 / 15:00 / 22:00 / 02:00 に自動投稿
